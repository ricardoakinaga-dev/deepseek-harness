# Web 实例生命周期改进

[English](web-instance-lifecycle.md) | 中文

## 概述

每次在本机运行 `dsh web` 都需要独立的监听端口和浏览器窗口。固定的默认端口会使第二个进程因 `EADDRINUSE` 而失败。随附的 Web bundle 负责 WebServer 配置，因此此分支将备用端口改为 `0`；操作系统分配空闲端口，绑定后打印的 URL 标识该实例。显式传入的 `--port` 仍保持原有含义。

## 完成条件

分配端口本身不能建立浏览器窗口的所有权。当前默认浏览器启动器只向操作系统传递 URL，没有可靠的窗口句柄；关闭窗口不会通知 Web 进程。完整的窗口所有权生命周期需要经过认证的客户端在线协议，能够容忍刷新和短暂断线，并在之后有界地关闭且只关闭所属进程。还需要记录 PID、端口、会话持久性、gateway 状态和关闭行为的双进程浏览器测试。在该协议和测试交付前，窗口关闭后进程仍保持运行，用户必须显式停止它。

## 兼容性与验证

此改进属于 `upstream-package-change`：profile overlay 无法改变随附 `dsh web` 命令的默认行为，且没有负责浏览器关闭的公开 Web 生命周期服务。端口分配不会改变 Session 数据或模型可见事件。请验证 Loader 解析后的默认端口和显式端口，再启动两个独立的 Web 进程，确认它们获得不同且可访问的端口。浏览器关闭协议需要另行提供生命周期、清理和浏览器证据，才能将此改进标记为活跃。
